# Material bruto do cliente

Coloque aqui o que o cliente mandou, sem editar: briefing antigo, catálogo, PDF de proposta, prints, planilhas, exports do Google Ads, mensagens.

**Quem lê isto é você, no chat** — não o agente de código. A partir do padrão v2.8, o material bruto é a matéria-prima da conversa com o `docs/PROMPT-FICHA-LP.md`, que organiza tudo, pergunta o que falta e devolve a ficha de execução. O agente no editor lê apenas `docs/FICHA-LP.md`.

O padrão prevalece: estrutura, ordem de seções e CTAs sugeridos aqui não são seguidos; o conteúdo é reaproveitado.

**Esta pasta fica fora do git** (só este README é versionado). É material bruto do cliente e não pode depender de o repositório da LP ser privado. O que a LP precisa dele vai, organizado, para a ficha e para `docs/BRIEFING.md`, que são versionados. Guarde o original também onde a agência guarda os arquivos do cliente.
